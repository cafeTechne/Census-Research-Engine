# Round 102 example: pooling state-specific uninsurance-poverty slopes (exploratory)

Author self-review, not independent; not a registered study. ACS 2019-2023 counties; slope of percent uninsured on percent below poverty within each of 12 states (HC1 SEs).

| State | Slope | SE |
| :--- | ---: | ---: |
| MI | 0.221 | 0.057 |
| NY | 0.178 | 0.036 |
| OH | 0.055 | 0.118 |
| PA | 0.018 | 0.109 |
| IN | -0.035 | 0.190 |
| IL | 0.168 | 0.050 |
| WI | 0.687 | 0.185 |
| MN | 0.355 | 0.082 |
| IA | 0.200 | 0.105 |
| MO | 0.345 | 0.113 |
| KY | 0.020 | 0.035 |
| WV | 0.043 | 0.060 |

**Pooled** (Paule-Mandel + Hartung-Knapp, truncated): 0.172 (90% CI 0.085 to 0.259); I2 72%; tau2 0.0197 with Q-profile interval 0.0055 to 0.0742 (validated).
Prediction interval for another state (exploratory): -0.097 to 0.441.
Leave-one-out pooled estimates ranged 0.148 (without WI) to 0.191 (without KY).
Meta-regression on state median household income ($1,000s; exploratory): 0.0074 per $1,000 (0.0001 to 0.0147); permutation p = 0.086.
Egger test (exploratory): intercept 1.39, p = 0.24. These are not publications, so asymmetry would reflect state size and heterogeneity, not publication bias.
